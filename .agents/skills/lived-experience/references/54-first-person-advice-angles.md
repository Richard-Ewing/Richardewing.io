### 8 Style-to-Mechanical Enforcement Gates

| Style Rule | Mechanical Enforcement Gate |
| :--- | :--- |
| 10th-thought opening | Delete first nine obvious takes |
| 10th predictive word | Use blunt spoken words like shelfware |
| Uneven paragraph rhythm | Mix one-liners with longer real stories |
| Zero AI bridge words | Strip `However,`, `Moreover,`, `Furthermore,`, and `That said,` starters |
| Zero rule-of-three symmetry | Break neat `"X isn't Y"` and three-item lists |
| Named human job titles | Name CFO, Engineering Manager, or Registered Nurse |
| Sibling opening lock | Zero shared five-word openings across sibling pages |
| Early natural endings | Cut summary paragraphs and fake morals |
