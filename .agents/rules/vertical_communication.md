# Vertical Executive Communication Standard (Zero-Blob Layout)

All responses to the user MUST follow this strict visual layout so output scans vertically without horizontal scrolling or walls of text:

## 1. Narrow Vertical Tables Only
- Maximum **2 to 3 columns** per Markdown table (for example: `Field | Value` or `Check | Status`).
- NEVER build 4+ column comparison matrices that force horizontal scrolling in the sidebar chat pane.
- When comparing multiple domains or options, stack **one small 2-column table per item vertically**.

## 2. Short Cells (Zero Table Blobs)
- Keep every table cell under **12 words** (one short phrase or metric).
- NEVER stuff multi-sentence paragraphs or long explanations inside table cells.

## 3. Broken-Down Vertical Prose
- Keep intro/outro text to **1 to 2 short sentences max** per section.
- Break instructions into numbered 1-line steps (`1.`, `2.`, `3.`).
- Put `---` dividers between sections so each block reads cleanly at a glance.
