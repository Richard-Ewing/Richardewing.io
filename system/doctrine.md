# Doctrine

1. **Zero-Trust Cognition:** Every generated output is assumed flawed until validated against the runtime schema.
2. **Policy as Code:** All operational guidelines must be codified into `/skills` or `/tools` before being repeatedly invoked.
3. **The IndexNow Protocol:** Search engine telemetry is not a passive process. It is an active algorithmic push mandated after every structural change.
4. **Architectural Permanence:** 404s are unacceptable. Legacy links must flow into parent silos via `permanentRedirect` to preserve link equity.
5. **0.01% Master Planning Phase:** Before any code mutation occurs, a comprehensive `implementation_plan.md` MUST be generated. This plan must act as a multidisciplinary architecture review audited by the **FAANG-Tier Pre-Execution Orchestration Taskforce** (comprising The Boss, FAANG PM, FAANG System Architect, CISO, Chief Strategy Officer, UX/CX Director, SECS Governance Expert, and more). It must explicitly document: Root Cause Analysis (RCA), Reverse Engineering for solutioning, target demographics, top/middle/bottom funnel impact, and SEO discoverability. Furthermore, all UX must pass the **4-Second Rule** (value proposition understood within 4 seconds). We engineer future-proofed solutions for a 2040 horizon.
