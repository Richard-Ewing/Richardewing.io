# ADR-0020: Clean-Room 9-System Assimilation, Streaming Generative UI, and Provenance Ledger

## Context
As `richardewing.io`, `exogram.ai`, and `careerwin.ai` scale across executive diagnostics, runtime AI governance, and consumer career readiness, nine external open-source repositories and design platforms were evaluated for architectural integration: `google/elephant-goldfish-model` (`Apache-2.0`), `thesysdev/openui` (`MIT`), `Nutlope/hallmark` (`MIT`), `Motionsites-AI/claude-skill` (split `MIT` code / proprietary `(c) MotionSites` media), `gitroomhq/postiz-app` (`AGPL-3.0`), `HKUDS/DeepTutor` (`Apache-2.0` Python), `mobbin.com` (official Antigravity partner MCP), `styles.refero.design` (`MIT` skill + paid MCP), and `spline.design` (+ Hana).

Root-cause analysis across our live codebase combined with empirical package manifest inspection surfaced five operational gaps alongside six supply-chain, licensing, bundle-weight, and design-system hazards:
1. **Same-Session Context Blindness and ADR Drift**: Authoring specifications and reviewing code inside the same long-context window causes agents to autocomplete unstated assumptions from conversation memory, while `docs/adr/ADR-*.md` previously had no automated check verifying that referenced repository files and invariants remain intact after subsequent refactors.
2. **Monolithic JSON Latency and Reflected HTML Risk in the Paid AI Integration Advisor**: In `app/api/ai-advisor/chat/route.ts` and `components/AdvisorChat.tsx`, `$249/mo` (`$1,997/yr`) subscribers waited 10 to 18 seconds on a blocking `client.interactions.create` call for Phase 5 to emit a verbose markdown-fenced JSON roadmap, while `components/AdvisorChat.tsx` rendered chat markdown via unescaped `dangerouslySetInnerHTML`. Meanwhile, direct `npm install` of `@openuidev/react-lang` and `@openuidev/lang-core` was rejected after empirical manifest inspection caught `postinstall.cjs` install telemetry, `devtoolsBootstrap.ts` development-time remote CDN script mounting, and Zod version divergence against our installed `zod` (`^4.3.5`).
3. **Commercial Wiring Regressions vs. Design-System Collisions**: TypeScript compilation alone does not detect when a UI edit accidentally deletes a `/schedule?source=` booking link, `<ScorecardCheckoutDrawer />`, or `/api/lead-capture` handler. However, installing `Nutlope/hallmark` themes or house gates (`Gates 54, 64, 65, 67`), `refero_skill` prompt-authority overrides, `Motionsites-AI` proprietary media/section-deletion rules, or `@splinetool/runtime` (`~970 KB` duplicate 3D runtime alongside our existing `three` / `@react-three/fiber` stack plus `'wasm-unsafe-eval'` CSP relaxation) would directly violate `DESIGN_CONSTITUTION.md` and our frozen `#FAF9F6` Warm Cream identity.
4. **Silent Fail-Open Governance in `lib/exogram.ts` and Unmeasured Retrieval / Curriculum Drift**: `exogramFetch` previously caught missing `EXOGRAM_API_KEY` values and HTTP `4xx/5xx` errors by returning `{} as T`, causing `evaluateAction()` to return `decision: undefined` instead of failing closed (`BLOCKED`). In addition, `lib/exogram.ts` lacked typed `L1 -> L2 -> L3` provenance contracts, retrieval lacked a deterministic `Recall@k / nDCG@k` math harness, and our Vault Curriculum modules (`app/lib/curriculum-data.ts`) lacked build-time SHA-256 source-drift fingerprints against `app/lib/concept-corpus.ts` and `app/lib/research-corpus.ts`.
5. **Post-Publish Distribution Friction vs. `AGPL-3.0` Contamination**: Publishing new diagnostics or essays left LinkedIn and X distribution to manual copy-pasting, yet importing code from `gitroomhq/postiz-app` (`AGPL-3.0`) or running its 5-container `NestJS` + `Temporal` + `Redis` stack is incompatible with proprietary SaaS licensing and Cloudflare Workers V8 isolates.

## Decision
1. **Goldfish Cold-Context Spec Split and Mechanical ADR Drift Auditing (`google/elephant-goldfish-model` Clean-Room Graft)**:
   - Upgrade `.agents/skills/spec-driven-development/SKILL.md` with three rules: (a) explicit `FeatureRange` vs. `DetailedRange` specification split, (b) silent cold-context comprehension paraphrase via a zero-history `research` subagent on multi-file Mode 3 builds without pestering the founder with trivial confirmation dialogs, and (c) a `1`-audit convergence cap scoped strictly to subjective subagent critiques while deterministic gates (`.agents/scripts/verify-qa.mjs`, `tsc`, `opennextjs-cloudflare build`) run unconditionally to exit code `0`.
   - Create `.agents/scripts/check-adr-drift.mjs` using Node and `ts-morph` to verify referenced repository paths across `Accepted` ADRs, enforce `scripts/patch-worker.mjs` `__RW_ADR_0019_EDGE_SHIELD__` presence, check fail-closed API guards, and emit `.scratch/adr-drift-report.md`.
2. **Machine-Locked Design Tokens, Mobbin UX Flow Sequencing, and `ts-morph` UI Integrity Gate**:
   - Create `.agents/skills/ui-ux-polish/references/DESIGN_TOKENS_LOCK.md` locking machine-readable visual tokens across all three properties (`richardewing.io` Concept B `#FAF9F6` Warm Cream, `exogram.ai` Living Tile governance tokens, and `careerwin.ai` Warm Paper and Coral 6th-grade consumer tokens) plus an Anti-Averaging Decision Ledger.
   - Update `.agents/skills/ui-ux-polish/SKILL.md` and `.agents/skills/visual-media-craftsmanship/SKILL.md` to wire the official `mobbin_mobbin` MCP strictly for UX flow state sequencing (drawers, empty/loading/error states, mobile tables) rendered inside our locked brand tokens, alongside 5 objective headless DOM assertions (`horizontalOverflow === false`, `0` console/network errors, `document.fonts.check()`, `>= 4.5:1` WCAG contrast, and `>= 44px` mobile tap targets).
   - Create `.agents/scripts/verify-ui-integrity.mjs` using `ts-morph` (`--before`, `--kept`, and Concept-B-safe floor gates blocking fake form sends, `w-[100vw]` horizontal bleed, and layout-thrashing `transition-all`) and wire Mode C into `.agents/scripts/verify-qa.mjs`.
3. **Zero-Dependency Streaming Generative UI Engine and Paid AI Advisor Remediation (`thesysdev/openui` Clean-Room Reconstruction)**:
   - Implement `lib/sovereign-ui-stream.ts` natively on `zod` (`^4.3.5`) with zero new npm packages: `defineWidgetCatalog`, `compileCatalogPrompt`, `createIncrementalUiParser` (blocking `javascript:` and `data:` URIs), and `hydrateLegacyRoadmapJson` for 100% backward compatibility with `components/AdvisorRoadmap.tsx` PDF exports and `ai_advisor_sessions.generated_plan`.
   - Create `components/ai-advisor/AdvisorStreamWidgets.tsx` (`MetricStrip`, `PainCostCard`, `StackReadinessCard`, `RoadmapPhaseCard`, `ExecutiveActionGate`) styled in Concept B tokens, and register `ai-advisor` and `advisor-roadmap` in `components/schedule/schedule-diagnostic-banner.tsx`.
   - Upgrade `app/api/ai-advisor/chat/route.ts` to support `@google/genai` SSE streaming (`body.stream === true`) with Cloudflare `getCloudflareContext().ctx.waitUntil(...)` protecting post-stream Supabase and Exogram writes, while preserving JSON responses when `body.stream` is omitted. Replace `dangerouslySetInnerHTML` and pre-existing em-dashes in `components/AdvisorChat.tsx` with pure React markdown/widget rendering.
4. **Fail-Closed Exogram Governance, `L1 -> L2 -> L3` Provenance Contracts, Retrieval Math Eval, and Curriculum Drift Fingerprinting (`HKUDS/DeepTutor` Architectural Port)**:
   - Refactor `lib/exogram.ts` onto a discriminated internal result with an `8,000ms` `AbortSignal.timeout` so `evaluateAction()` fails **closed** (`decision: 'BLOCKED'`) whenever `EXOGRAM_API_KEY` is missing or upstream calls fail, `vaultSearch()` reports honest `degraded` metadata, `vaultSearchStrict()` throws explicit transport errors for benchmarks, and versioned `ExogramL1Event`, `ExogramL2Claim`, and `ExogramL3Synthesis` contracts are exported without breaking existing callers.
   - Create `.agents/scripts/run-retrieval-eval.mjs` computing deterministic `Recall@k`, `Precision@k`, `nDCG@k`, `MRR`, and `Hit@k` with `--diff` comparison, plus `.agents/scripts/check-curriculum-health.mjs` computing build-time SHA-256 dependency fingerprints across `app/lib/curriculum-data.ts`, `app/lib/concept-corpus.ts`, and `app/lib/research-corpus.ts`.
5. **Air-Gapped Step 6 Sovereign Distribution Compiler and Human-Gated Queue (Zero `AGPL-3.0`)**:
   - Create `.agents/scripts/compile-distribution-pack.mjs` generating HWS v2.0 linted, UTM-tagged LinkedIn, X, and Boardroom Scorecard drafts in `.scratch/distribution-queue/<slug>.json` with `status: "pending_human_approval"`.
   - Author `docs/sql/20261101_sovereign_distribution_queue.sql` defining `public.sovereign_distribution_queue` with `service_role`-only RLS, `approved_by_human_at IS NOT NULL` enforcement before dispatch, and `claim_due_distribution_jobs(batch_size INT)` using `FOR UPDATE SKIP LOCKED`.
6. **Decoupled Cross-Property Rollout Firewall (`exogram.ai` and `careerwin.ai`)**:
   - Keep `richardewing.io` free of foreign application routes. Next-step companion rollouts execute directly inside their own repositories: (a) `exogram.ai` implements server-side `/v3/vault/store-provenance` and `/v3/vault/graph` endpoints backing `lib/exogram.ts`, `ExogramLivingTiles` on `sovereign-ui-stream.ts`, and upstream Spline/Hana `.glb` -> `@react-three/fiber` meshes with `prefers-reduced-motion` WebP posters; (b) `careerwin.ai` applies `mobbin_mobbin` mobile onboarding/scorecard flow sequencing and a plain-English `L1 -> L2 -> L3` candidate skill-bank under its Warm Paper and Coral token lock.

## Status
Accepted

## Consequences
Positive:
- Eliminates third-party supply-chain, telemetry, CSP, and `AGPL-3.0` licensing traps before any external dependency enters `package.json` or git history.
- Cuts AI Integration Advisor structured widget token overhead by over 50%, streams progressive ROI and roadmap cards within ~1.5 seconds for `$249/mo` subscribers, and closes the `dangerouslySetInnerHTML` XSS vector in `components/AdvisorChat.tsx`.
- Closes the fail-open defect in `lib/exogram.ts` so `evaluateAction()` deterministically returns `BLOCKED` on missing credentials, network failures, or timeouts, while establishing typed `L1 -> L2 -> L3` provenance contracts and math-graded `nDCG@k` retrieval benchmarks.
- Protects conversion links, checkout drawers, and wired `/api/*` forms against silent UI refactor regressions via `ts-morph` AST graph verification, and detects upstream research/concept drift across Vault Curriculum modules at build time.
- Automates HWS v2.0 post-publish LinkedIn and X draft compilation behind a database-enforced human approval gate (`approved_by_human_at IS NOT NULL`) and concurrency-safe `FOR UPDATE SKIP LOCKED` job claiming.

Negative/Considerations:
- Maintaining our own zero-dependency positional UI stream runtime (`lib/sovereign-ui-stream.ts`) means grammar extensions are owned in-house rather than inherited upstream, though its focused surface area and Zod v4 validation make maintenance straightforward and eliminate third-party bundle/telemetry risk.
- Running `verify-ui-integrity.mjs` Mode C inside `verify-qa.mjs` adds a lightweight AST/source check on git-modified `.tsx` and `.css` files during pre-deploy verification, trading ~0.3 seconds of local QA runtime for deterministic protection against fake form sends and layout overflow bugs.
- `public.sovereign_distribution_queue` DDL (`docs/sql/20261101_sovereign_distribution_queue.sql`) must be applied in Supabase before enabling live OAuth webhook dispatch Workers; local `.scratch/distribution-queue/` compilation operates immediately with zero database dependency.
